## Key Decisions (oltre a quelle nei story file 8-*.md e negli handoff archiviati)

- **Postura anti-abuso PPR**: honeypot = difesa primaria; rate limit = controllo SOFT (TOCTOU sotto burst concorrente dimostrata: 20 parallele → 14 righe; `x-forwarded-for` client-trusted senza proxy davanti). ACCETTATO per contratto di story/spine MVP — rivisitare solo se si osserva abuso o al deploy dietro proxy fidato.
- **Risposta pubblica minimale** `{status:'PENDING'}` senza id enumerabile; `submitterIp` MAI nei DTO.
- **Numerazione PPR**: per anno Europe/Rome, contatore dedicato `PprCounter` (non max+1, non sequence DB), gapless garantito dall'ordine lock-riga→upsert-contatore.
- **`AppSetting`** è ora il posto delle config admin (istruzioni operative IT/EN, default tassa in centesimi come stringa); niente pagina `/settings` generale (resta deferred) — le config PPR vivono nella pagina coda, gated `settings.manage`.
